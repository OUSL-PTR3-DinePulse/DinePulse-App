# ✨ DinePulse-App ✨ 
**A Smart Feedback System for Small Restaurants**

DinePulse is a real time feedback web application designed specifically for small restaurants to capture customer sentiment instantly and improve service quality. By replacing outdated paper based methods with an engaging, emoji driven digital interface, DinePulse helps restaurant owners respond to feedback in real time, enhance customer satisfaction and build lasting loyalty.

---

## ✨ Features  

- **Emoji Based Feedback** – Customers rate their experience quickly using happy, neutral or sad emojis with an optional comment box for details.  
- **Real Time Owner Alerts** – Instant notifications are sent to the restaurant owner when critical (negative) feedback is submitted, enabling immediate intervention.  
- **Customer Loyalty Rewards** – After submitting feedback, customers receive a "Thank You" message along with a discount coupon (QR code) for their next visit.  
- **Analytics Dashboard** – Owners can track satisfaction trends, view performance insights and identify strengths/weaknesses in food and service.  
- **Multilingual Support** – Feedback forms available in **English** and **Sinhala**.  
- **Secure & Scalable** – Built with modern security practices and cloud-based infrastructure to ensure reliability.
